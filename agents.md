# Agent Instructions

## Project Overview

This project is a web-based quiz application
developed for a university course.

## General Instructions

1. Keep the code simple, clean and readable.

2. Use meaningful names for variables and functions.

3. Add comments to explain complex code.

4. Follow the existing project structure.

5. Test the application after making changes.

6. Do not remove existing functionality without
   checking its impact.

7. Make sure CSV files are processed correctly.

8. Keep the user interface simple and intuitive.

## Development Guidelines

- Use HTML for the application structure.
- Use CSS for styling.
- Use JavaScript for application logic.
- Check for errors before committing changes.
- Document important changes.

## Goal

The goal is to develop a functional and
user-friendly quiz application.
