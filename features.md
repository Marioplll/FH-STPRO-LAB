# Features

1. Quiz Selection
   Users can select a quiz from available topics.

2. Question Display
   The application displays questions to the user.

3. Answer Selection
   Users can select an answer for each question.

4. CSV File Support
   Quiz questions can be imported from CSV files.

5. Score Calculation
   The application calculates the quiz score.

6. Results Display
   Users can view their results after completing a quiz.

7. User Interface
   The application provides a simple interface
   for navigating through quizzes.
