# Agent Instructions

## Project Overview

This project is a simple Java quiz application.

## General Instructions

1. Write clean and readable Java code.
2. Use meaningful variable and method names.
3. Add comments to explain important parts of the code.
4. Keep the application simple and beginner-friendly.
5. Test the application after making changes.
6. Do not remove existing features.
7. Follow the existing project structure.

## Development Guidelines

- Use Java as the programming language.
- Keep the quiz questions simple.
- Check user input for errors.
- Display the final quiz score.

## Goal

Create a simple quiz application that allows users
to answer questions and receive a final score.
